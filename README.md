# MOAI // VJ — phone remote

Phone control surface for a TouchDesigner VJ set (effects, models, camera, audio reactivity, blackout).

Open the link that TouchDesigner shows in `CONTROLS → Master → Phone link` (it carries a private pairing key after `#k=`).
The page talks to TouchDesigner through a public MQTT relay, so phone and computer don't need to be on the same network.
